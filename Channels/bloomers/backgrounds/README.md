# bloomers — green-screen background assets

Drop the files here, then tell me to look:

- **base.png**            — the flowerLESS watercolor background (blue, no flowers on it).
- **flowers/*.png**       — each individual flower as its OWN transparent PNG (one file per
                            flower), so each can shake independently. Name them anything
                            (e.g. pink-01.png, blue-02.png). Leaves too if you want them.

Also helpful when you have it:
- **greenscreen-sample.mp4** — a short (5-10s) clip of you on your ACTUAL green-screen setup,
  so I can tune the key strength to your real green + lighting.
